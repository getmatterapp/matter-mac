# Matter for Mac

Downloads for the Matter for Mac beta. Get it from **[getmatter.com/mac](https://www.getmatter.com/mac)**.

This repository holds release builds only. Each release has two signed, notarized disk images:

- `Matter-Apple-Silicon.dmg` for Macs with Apple silicon (M1 and later)
- `Matter-Intel.dmg` for Intel Macs

Matter for Mac requires macOS 13 Ventura or later. Open the disk image and drag Matter into Applications.
